# **MIMIC Multimodal AI**

This project provides a **multimodal radiology AI pipeline** using the **MIMIC-CXR dataset**, supporting:

- **Contrastive learning** (CLIP-style): Learns a shared representation between chest X-ray images and radiology reports.
  
  **Use Cases:**
  - Retrieve similar prior cases from hospital archives
  - Search imaging databases using report text
  - Build case-based clinical decision support tools
- **Disease classification** (multi-label): Automatically predicts common thoracic findings from chest X-rays (e.g., pneumonia,
  cardiomegaly, pleural effusion).

  **Use Cases:**
  - Automatically label large research datasets
  - Flag urgent abnormalities (e.g., pneumothorax)
    
- **Joint training** (classification + contrastive): Combines disease classification and image–report alignment to build stronger
  multimodal models.

  **Use Cases:**
  - AI systems that can both detect diseases and retrieve similar cases
  - Multimodal clinical search tools
    
- **Multimodal report generation** (BioViL → MedPaLM-M or local LLM): Generates a draft radiology report from a chest X-ray using BioViL
  image features and a medical language model.

  **Use Cases:**
  - Draft reports for radiologist review
  - Reduce reporting time in high-volume workflows

## **Requirements**

    pip install -r requirements.txt
---

## **Configuration**
Edit config.yaml for dataset paths, hyperparameters, and training mode:

    mode: "joint"  # Options: "contrastive", "classification", "joint", "report_generation"
    mimic_cxr_root: "/path/to/MIMIC-CXR/images"
    preprocessed_csv: "./data/mimic_preprocessed.csv"
    output_dir: "./checkpoints"
    batch_size: 16
    epochs: 3
    lr: 2e-6
    alpha: 0.5  # weight for contrastive loss

---
## **Preprocessing MIMIC-CXR**
    python preprocessing.py

- This creates a CSV with columns:

  - file_path → path to image
  - report_text → corresponding radiology report
---

## **Training**
    python train.py

  | Mode              | Description                                           |
  | ----------------- | ----------------------------------------------------- |
  | classification    | Train disease classifier only                         |
  | contrastive       | Train CLIP-style embedding alignment only             |
  | joint             | Train classification + contrastive jointly            |
  | report_generation | Generate reports using BioViL → MedPaLM-M / local LLM |

---

## **Report Generation**

- Uses BioViL embeddings as input.
- Supports MedPaLM-M API (inference-only) or local LLM for fine-tuning.

Example Usage:

    from report_generation import ReportGenerator
    rg = ReportGenerator(image_encoder=base_model, report_model_name="google/medmimic-t5-base")
    reports = rg.generate_report(images)  # images: torch tensor batch
    print(reports)
